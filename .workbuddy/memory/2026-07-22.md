### 症状
关系页(走 /api/family)、记录页(走 /api/events) 加载失败/无数据；首页 dashboard 正常。

### 根因（curl 实测确诊）
proxy.ts + session.ts + auth/auto + requireCultivator 机制**本身正常**：带 cs_session cookie 时代理正确注入 x-user-id，requireCultivator 能找到用户。
缺口在客户端建号流程：首页「快速生成」`handleQuickCreate`(page.tsx:70) 直接 `POST /api/cultivator` 建号，而该路由**不下发 cs_session cookie**（仅 /api/auth/auto 登录页下发）。
→ 走快速生成进来的用户无 cookie → requireCultivator 返回 401 → 关系页/记录页数据加载失败。
dashboard 走 /api/cultivator GET（**不**校验 x-user-id，按 query 查库）故正常。完美对应"只有关系页/记录页挂"。

### 修复（2 文件，改动最小）
