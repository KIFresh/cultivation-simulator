# 地点生态扩展方案（Location Ecosystem Expansion）

> 状态：**设计中（待用户拍板后再动工）** ｜ 关联：`地点功能补全方案.md`（核心 14 行动 + 本次新增 3 金币行动已完成）
> 立项来源：2026-07-23 用户选「补全 + 扩展地点生态」。本方案为"扩展"部分，需单独排期。

## 现状盘点

- 13 个地点，每个 1–2 条专属行动（共 16 条：`PARK_*`/`KINDER_*`/`LIB_*`/`CLINIC_*`/`FURN_*`/`MALL_*`/`DOWNTOWN_*` + `CLINIC_TREAT`/`CITY_DINE`）。
- 行动现状：仅产出**属性经验 + AI 叙事**；地点间无差异化事件、无地点专属 NPC、经济仅有 travel 费 + 静态商店 + 3 个金币消耗行动。
- 已有可复用底座：
  - `storyEntries`（记忆，机制层叙事，零 schema）
  - `npcRelations`（通用关系表，支持任意 `type`，邻居已用 `type:"neighbor"`）
  - `inventory`（背包，商店物品 `SHOP_ITEMS` 已存在）
  - `gold`（金币，凡人消费）/ `spiritStone`（灵石，修仙消费，由并行会话落地中）
  - 行动金币/健康扣费通道（`/api/action` 已支持 `goldCost`/`healthGain`）

## 设计铁律

1. **零 schema 迁移**：全部复用 `storyEntries` / `npcRelations` / `inventory` / `gold` / `spiritStone`，不新增 Prisma 字段。
2. **尽量避开 11 个冻结文件（FW）**：新逻辑走新 `lib` 模块 + 新 API route + 新页面（均非 FW）；若必须动 `dashboard/page.tsx` 等 FW，走 chmod 444 + skip-worktree 防御提交。
3. **种子可复现**：地点事件/相遇用 `hashSeed(userId+date+location)` + `mulberry32()`（同 weather/short-video/reading 模式），保证公平与可调试。
4. **货币按双货币裁决**：凡人期地点消费用 `gold`，修仙期专属消费用 `spiritStone`，不在方案内混用。

## 三支柱

### A. 地点随机事件（Location Random Events）★ 推荐 Phase 1

每个地点配一个轻量事件池，访问/执行地点行动时按概率触发。

- 新增 `src/lib/location-events.ts`（Safe）：
  - `LOCATION_EVENT_POOL: Record<locationId, LocationEvent[]>`
  - `LocationEvent { id, title, description, weight, minAge, effects: { attrDeltas?, goldDelta?, healthDelta?, npcMeet?: npcId, memory?: boolean } }`
  - `rollLocationEvent(userId, locationId, age, seed)` → 命中事件或 null（~25% 触发）。
- 新增 `src/app/api/location-event/route.ts`（Safe）：
  - `GET` 为当前地点摇一个事件；`POST` 应用 effects（复用 `/api/action` 的 updateData 写法：属性走 `calculateAttributeExp`、金币走 `increment`、健康走 `clamp(100)`、相遇写 `npcRelations`、需记忆的 push 进 `storyEntries`）。
- UI：dashboard 顶部弹一个「地点奇遇」卡片（复用行动结果卡样式），点开看叙事。
- 示例事件：公园(捡到钱包+gold / 走失小孩+心智)、图书馆(绝版书+悟性)、商场(限时折扣标记)、市区(街头奇人+魅力)、诊所(义诊日+健康)。

### B. 地点专属 NPC（Location NPCs）★ Phase 2

每个地点 1–2 个常驻 NPC，复用邻居交互模式。

- 新增 `src/lib/location-npcs.ts`（Safe）：照搬 `neighbors.ts` 结构，`npcRelations` 用 `type:"location_npc"` 区分；含 `rollInitialLocationNpcs` / `interactLocationNpc`（闲聊/送礼/帮忙）。
- 相遇触发：归入 A 的事件类型 `npcMeet`（首次遇见写入 `npcRelations`，之后可在该地点互动）。
- 新增 `src/app/location-npcs/page.tsx`（Safe，仿 `/neighbors` 暗色页）：列出当前地点 NPC + 互动按钮 + 好感进度。
- 与「邻里」系统零冲突（type 不同），且天然补足"地点有人气"。

### C. 地点经济深化（Location Economy）★ Phase 3（依赖灵石字段成熟）

把静态商店变成可交互的"地点商铺"，让消费有意义。

- 新增 `src/app/shop/page.tsx`（Safe）或按地点分标签：浏览 `SHOP_ITEMS`，用 `gold`/`spiritStone` 购买，写 `inventory`（复用 `inventory-utils`）。
- 价格浮动：A 的事件类型 `discount`/`surge` 给该地点下一次购买打折/加价（内存态或写 `cultivator` 既有 JSON 字段）。
- 与已落地的 3 个金币消耗行动构成"消费→收益"闭环（看病+健康、美食/下馆子+属性）。

- 不碰 rogue 未批准的"地点系统"越权代码（`localNPCs` 等），仍维持冻结。
