# 系统 GDD · 炼丹系统（Alchemy System）

> 范围：配方、丹炉、品质、丹毒、成功率
> 代码锚点：`src/lib/alchemy-data.ts`（静态常量）+ Zustand `refinePill` 流程

---

## ① 概述
炼丹是把"探索掉落的材料"转化为"可消费成长资源"（恢复/经验/力量/突破/解毒）的核心转化系统。配方与丹炉均为**静态常量**（不建数据库表），品质由丹炉权重池随机决定（乘区 0.5/1.0/1.5/2.0），服用丹药累积丹毒(`toxicity`)，需用洗髓丹化解。系统承接战斗/奇遇掉落的灵草妖丹，反哺修炼与突破。

## ② 设计目标
1. **资源转化闭环**：材料（野外采集/战斗掉落）→ 丹药 → 即时/永久增益，给"刷材料"以明确目的。
2. **丹炉即投资**：4 档丹炉价格/成功率/品质权重差异，构成中期金币 sink 与品质博弈。
3. **丹毒制造权衡**：高频嗑药累积丹毒，逼迫玩家在"短期 buff"与"长期毒性"间权衡（心流张力）。
4. **天赋差异化**：`丹道圣手`(+15%)/`炼器鬼手`(+5%) 让天赋影响炼丹，强化 Build 感。

## ③ 核心机制
- **配方** `ALCHEMY_FORMULAS`（5 个，静态）：
  - `formula_recovery` 凝血丹：成功率85%，材料 凝血草×2+清泉水×1，难度1，minRealmLevel 0。
  - `formula_exp` 聚气丹：成功率65%，聚灵草×3+一阶妖丹×1，难度2，minRealmLevel 1。
  - `formula_strength` 淬骨丹：成功率50%，铁木花×2+妖兽骨粉×1，难度2，minRealmLevel 2。
  - `formula_breakthrough` 筑基丹：成功率30%，筑基果×1+百年人参×2，难度3，minRealmLevel 5。
  - `formula_detox` 洗髓丹：成功率15%，冰心莲×1+无根水×2，难度3，minRealmLevel 3。
- **丹炉** `FURNACES`（4 种，静态）：破烂青铜炉(100, +0%, 权重 70/25/5/0) · 精铁丹炉(500, +5%, 40/40/18/2) · 紫金八卦炉(3000, +15%, 0/10/60/30) · 乾坤造化鼎(20000, +30%, 0/0/30/70)。
- **品质乘区** `getQualityMultiplier(itemId)`：`_low`=0.5 / `_mid`=1.0 / `_high`=1.5 / `_perfect`=2.0（按物品 ID 后缀）。
- **丹毒** `getToxicityGain(quality)`：low=10 / mid=5 / high=1 / perfect=0（服用时累加至 `toxicity`）。
- **品质随机** `determineQuality(weights)`：按丹炉 `qualityWeights` 累加权重掷骰定档。
- **天赋加成** `getTalentBonus(talentsJSON)`：`pill`(丹道圣手)+15 / `forge`(炼器鬼手)+5（JSON 解析，异常回退 0）。
- **丹毒两轴常量（🟡-1）**：`RESISTANCE_MAX=10`（per-type 耐药性封顶层数）、`RESISTANCE_DECAY_PER_LEVEL=0.07`（每层效果 −7%）、`RESISTANCE_FLOOR=0.3`（效果折扣下限）、`DETOX_PER_QUARTER=3`（**每季**全局丹毒自然消退量）、`TOXICITY_CAP=100`（丹毒上限）。轴一·耐药性：`applyResistance` 按丹药 id 独立累加 per-type 计数；`getResistanceFactor` 按「服用前」层数给折扣 `max(0.3, 1−层数×0.07)`（首次满效、重复嗑同种递减，不连坐其他丹药）。轴二·丹毒：`applyToxicity` 累加、`decayToxicity` 每季 −3 自然消退（`decayToxicity` 由 `advance-quarter` 调用）。
- **丹道圣手品质偏移** `getTalentQualityLift(talentsJSON)`：丹道圣手(`pill`)返回 0.15，将丹炉品质桶向上挪一档（low→mid→high→perfect，总量守恒，避免概率堆到最高桶破坏平衡）；`determineQuality(weights, qualityLift)` 已接入该偏移，与成功率加成（`getTalentBonus`）共同构成天赋差异化。
- **实际炼制流程**：由 Zustand `refinePill` 编排——校验材料/境界门槛 → `成功率 = baseSuccessRate + furnaceBonus + talentBonus`（封顶 100）→ 成功则 `determineQuality` 定品质 → 扣材料、产丹、累加丹毒；失败则耗材料无产出。

## ④ 数值/平衡
| 配方 | 成功率(基础) | 难度 | 境界门槛(minRealmLevel) | 材料 |
|------|--------------|------|------------------------|------|
| 凝血丹 | 85% | 1 | 0 | 凝血草×2 + 清泉水×1 |
| 聚气丹 | 65% | 2 | 1 | 聚灵草×3 + 一阶妖丹×1 |
| 淬骨丹 | 50% | 2 | 2 | 铁木花×2 + 妖兽骨粉×1 |
| 筑基丹 | 30% | 3 | 5 | 筑基果×1 + 百年人参×2 |
| 洗髓丹 | 15% | 3 | 3 | 冰心莲×1 + 无根水×2 |

| 丹炉 | 价格 | 成功率加成 | 品质权重 low/mid/high/perfect |
|------|------|-----------|-------------------------------|
| 破烂青铜炉 | 100 | +0% | 70/25/5/0 |
| 精铁丹炉 | 500 | +5% | 40/40/18/2 |
| 紫金八卦炉 | 3000 | +15% | 0/10/60/30 |
| 乾坤造化鼎 | 20000 | +30% | 0/0/30/70 |

- **丹毒累积**：每次服用按品质加 0~10 点（`getToxicityGain`）；衰减已接——`advance-quarter` 每**季度**调用 `decayToxicity` 自然消退 **−3**（`DETOX_PER_QUARTER=3`，即每自然年 −12），封顶 `TOXICITY_CAP=100`，配合 tox≥100 年维度 30% 走火入魔（见风险项 2）。
- **品质产出**：青铜炉几乎不出 high/perfect；乾坤鼎必出 high/perfect，构成强金币 sink。

## ⑤ 玩家流程
1. **集材料**：野外 `GATHER` 采集灵草、战斗掉落妖丹/骨粉、商店购买。
2. **解锁配方**：`unlockedFormulas`(DB 字段) 控制可见配方；初始应至少含凝血丹。
3. **选丹炉**：`furnaceEquipped` 默认 `bronze_furnace`，可购更高级炉替换。
4. **炼制**：炼丹面板选配方 → `refinePill` 校验材料/境界 → 掷成功率 → 成功定品质产丹+丹毒，失败耗材。
5. **服用**：经 `/api/cultivator/use-item` 消费丹药——丹药分支**优先匹配 baseId**（不再先查 ITEMS 完整 id 导致死链）；调用 `computePillConsumption` 做两轴结算：`qualityMultiplier` 缩放效果、`resistanceFactor`（按**服用前**耐药性折扣，首次满效、重复嗑同种递减至 `RESISTANCE_FLOOR=0.3`）作用于效果、`getToxicityGain` 累加全局丹毒 `toxicity`、`applyResistance` 累加 per-type 耐药性 `resistance` 并持久化；洗髓丹（`isDetox`）按品质真正减毒、不建耐药性。炼丹筑基丹 `productBaseId` 由 `breakthrough_pill`→`foundation_pill`，避免与商店破境丹（`breakthrough_pill`，tempBuff）撞 id。

## ⑥ 界面与反馈
- **炼丹面板(alchemy-panel)**：列出已解锁配方（成功率预览 = 基础+炉+天赋）、材料是否齐全、丹炉选择、品质概率分布提示。
- **炼制反馈**：成功显示产出丹药品质（low/mid/high/perfect 视觉区分）+ 丹毒 +X；失败显示"丹毁"叙事。
- **背包(inventory-panel)**：丹药按品质后缀 `_low/_mid/_high/_perfect` 分条目显示，服用时展示缩放后效果。
- **丹毒/耐药提示**：HUD/状态条显示全局 `toxicity`（☠️ 丹毒，高毒时警示，是否联动心魔/负面状态待定）；轴一·per-type 耐药性（🛡️ 耐药 `resistanceCount`）已落地显示（按丹药 id 各自计数），双轴可视闭环已通。

## ⑦ 依赖关系
- **上游**：修炼体系（境界门槛 `minRealmLevel`）、经济与商店（材料/丹炉购买）、战斗与奇遇（材料掉落）、NPC（坊市 alchemist 可售材料）。
- **下游**：修炼体系（聚气丹→经验、淬骨丹→永久力量）、突破（筑基丹为刚需）、寿命（丹毒是否折寿待定）、心魔（待确认丹毒是否诱发）。
- **兄弟**：功法（部分功法/天赋影响炼丹）、叙事 AI（炼丹失败/成功叙事）。

## ⑧ 风险与开放问题
1. **设计文档自相矛盾（需主理人裁决）**：炼丹设计文档 §八"决策表"写"配方数据→数据库表"，但正文 §4.1/§4.7、实施计划与代码 `alchemy-data.ts` 注释均明确为**静态常量**。GDD 以代码为准（静态常量）。文档需修订。
2. **丹毒衰减（已接，代码为权威源）**：`alchemy-data.ts` 常量 `DETOX_PER_QUARTER=3` 即**每季**自然消退 3 点（每自然年 −12），由 `advance-quarter` 调用 `decayToxicity` 落实，`TOXICITY_CAP=100`。旧 GDD §④ 写作「每自然年 −5（÷4 写入季度，即 −1.25/季）」与代码不符，已按代码更正（见 Edit 2 行）；差异不影响闭环，登记于 CONSISTENCY（🟡-1 丹毒衰减口径）。
