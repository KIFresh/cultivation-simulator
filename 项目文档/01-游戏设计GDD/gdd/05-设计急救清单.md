## T0 — 必停线（游戏无法启动 / 核心流程阻断）

| # | 检查项 | 确认命令 | 通过标准 |
|---|--------|----------|----------|
| 1 | Prisma Schema 有效 | `npx prisma validate` | `Schema is valid` |
| 2 | Prisma Client 生成 | `npx prisma generate` | 无报错 |
| 3 | TypeScript 编译 | `npx tsc --noEmit` | 0 errors |
| 4 | Next.js 构建 | `npm run build` | `Compiled successfully` |
| 5 | DB migration up-to-date | `npx prisma migrate status` | `Database schema is up to date` |

**修复指引**：
- Schema 失效 → 检查 `schema.prisma` 是否有未闭合的 fields/models
- Build 失败 → `npx next build` 详细日志，常见：类型错误、未使用的 import、导出路径错误
- Migration 漂移 → `npx prisma migrate dev` 生成增量 migration
